# 実地検査対策チェックリスト（現場スタッフ向け）

このチェックリストは、実地検査の準備を段階的に進めるための詳細ガイドです。各項目の具体的な作業内容、実施方法、確認項目を記載しています。

**進捗状況を「未着手」→「進行中」→「完了」と更新してください。**

## 【STEP 3】一般的な指導事項への対応

実地検査で一般的に指摘される13の項目です。各項目に対して確認チェックリストを記載しています。

| 指導事項 | 対応内容 | 確認チェック項目 | 進捗 |
|---------|--------|-----------------|------|
| **1. 職員研修の実施** | 虐待防止、個人情報保護、障害者理解など職員研修 | □ 年間研修計画がある □ 虐待防止研修（年1回以上） □ 個人情報保護研修 □ 支援スキル研修 □ 参加者記録がある | 未着手 |
| **2. 利用契約と同意** | 利用契約書、支援内容、同意書が明確 | □ 全利用者と契約書がある □ 契約内容が最新版 □ 利用者・保護者署名がある □ 支援内容が具体的 □ 料金が明記 | 未着手 |
| **3. 支援計画の作成** | 個別支援計画が作成され実行されている | □ 全利用者に計画がある □ 利用者目標が記載 □ 支援内容が具体的 □ 実施記録がある □ 定期見直し（年1回以上） | 未着手 |
| **4. 勤務・給与管理** | 職員の勤務時間、休暇、給与が適切に管理 | □ 勤務表が整備 □ 超過勤務記録 □ 給与明細配布 □ 社会保険加入 □ 労働契約書完備 | 未着手 |
| **5. 個人情報保護** | 利用者の個人情報が適切に保護される | □ 保護方針がある □ ファイルが鍵付き □ アクセス権限が制限 □ 使用目的が明確 □ 研修がある | 未着手 |
| **6. 虐待防止体制** | 虐待防止委員会、相談窓口、報告体制が確立 | □ 虐待防止委員会がある □ マニュアルがある □ 外部相談窓口明記 □ 報告フロー図がある □ 研修が実施 | 未着手 |
| **7. 差別防止対策** | 障害者差別解消法への対応と合理的配慮 | □ 差別禁止方針がある □ 合理的配慮の具体例 □ 相談窓口がある □ 研修がある □ 改善計画がある | 未着手 |
| **8. 権利の明確化** | 利用者が権利と責任を理解している | □ 説明書がある □ 権利・責任が具体的 □ 利用者署名がある □ 質問・不満に対応 □ 改善記録がある | 未着手 |
| **9. 会計管理と監査** | 収支が適切に管理され監査が実施されている | □ 会計方針書がある □ 領収書が整理 □ 会計記録がある □ 決算を監査に提出 □ 対応記録がある | 未着手 |
| **10. 施設・設備安全** | 施設・設備が安全に管理されている | □ 安全点検計画がある □ 定期点検実施 □ 点検記録がある □ 不具合は速やか修理 □ 防災訓練（年2回以上） | 未着手 |
| **11. 苦情・相談対応** | 利用者・保護者の苦情・相談が適切に対応 | □ 相談窓口がある □ 複数の相談方法 □ 記録がある □ 対応経過・結果を記録 □ 改善事項を実行 | 未着手 |
| **12. 支援記録と報告** | 毎日の支援が適切に記録され報告されている | □ 日誌が毎日記録 □ 支援内容が具体的 □ 利用者の様子を記載 □ 特記事項を記載 □ 保護者に定期報告 | 未着手 |
| **13. スタッフ健康管理** | 職員の健康診断、メンタルヘルスケア、労働条件 | □ 年1回以上健診 □ 健診結果を記録 □ 相談窓口がある □ 労働条件が法令順守 □ 環境改善に取組 | 未着手 |

## 注意事項

- 各項目の実施状況を「未着手」→「進行中」→「完了」と更新してください
- 不明な点は管理者に相談してください
- 書類の整理、清掃は計画的に進めることが大切です
- 実地検査は通常1～2日間です。スタッフ全員で協力してください
- このファイルはExcelに変換して使用することもできます
