# 電話応対マニュアル

## はじめに

電話応対は、お客様との **ファーストコンタクト** となります。
電話応対で弊社の印象の全てが決定すると言っても過言ではありません。

実際に「初頭効果」という実験結果も確認されており、最初に得た情報が後々まで影響を与え、そのものを判断する材料として影響を及ぼします。また初頭効果の持続期間は非常に長く、**半年程度は印象に残ることが証明されています。**

---

## 電話応対の4つのポイント

1. **言葉使い**
2. **笑声**
3. **スピード**
4. **イントネーション**

### 1. 言葉使い

今どきの話し方が口癖になっていて、どんな状況でもとっさに使用してしまっている場面はありませんか?

今どきの話し方は自身の見られ方を大きく左右するポイントで、損をしてしまうことも多くある言葉です。

**注意すべきポイント：**

#### 語尾伸ばし
「◯◯じゃないですか~」「ですから~」「思って~」「◯◯なんで~」

という語尾を伸ばした言葉は相手に幼稚で馴れ馴れしい印象を与えます。

✓ **きちっと言い切ることで、清々しい爽やかな印象になります。**

#### 半クエスチョン系
「貯金?した方がいいと思うんですよ」「コンプライアンス的に?どうかな」

会話の途中で意味もなく上がる言葉で、耳障りな印象ですし、聞き手に自信がないという印象を与えかねません。

#### 無駄な言葉
「~の方」「~とか」「~みたいな」「~という形」「(なんでも)逆に」

というような言い方を多用すると、言葉遣いが未熟な人という印象になりかねません。

#### 文節止め
「~なんですが」「~ですけれども」「~ですので」

という言葉遣いは、まだ会話が続いているように聞こえて聞き手を混乱させます。

また、高圧的な印象を与える言葉遣いですので、絶対に避けましょう。

---

### 2. 笑声（しょうせい）

電話対応は、普段のコミュニケーションと違い、お互いの顔を直接確認することができません。

いつもと変わらない声のトーンで電話応対を行うと機器の性能上『暗い』『元気がない』『やる気がない』などの印象を与えてしまいかねません。

**トーン調整ガイド：**
- **女性：** いつもの会話より『1トーン』上げて会話
- **男性：** いつもの会話より『2トーン』上げて会話

✓ 『笑顔』の『声』= **『笑声』** を意識して電話応対を行いましょう。

---

### 3. スピード

電話応対では、話すスピードが重要になります。

**スピードが速い場合：**
- 『忙しそう』『急かされている』という印象
- 『適当に対応されそう』などのイメージ

**スピードが遅い場合：**
- 忙しい方にゆっくり会話を行うとストレスに感じる場合もあります

**ポイント：**
聞き手がちょうどいいと感じるスピードを読み取り、臨機応変に応対することが大切です。

基本的には **相手の話すスピードの『ワンテンポ遅く』** を意識して会話を行うと良いとされています。

---

### 4. イントネーション

言葉の山を意識して『イントネーション』に気をつけて応対を行います。

言葉の山を意識することによって、自身の伝えたい感情等を正確に表現することが出来ます。

**注意点：**
強弱が無いと『感情が薄い』と感じられてしまい、支援への思いが上手く伝わらない可能性があります。

また、就職活動をサポートする立場として、しっかりとした言葉使いや標準語での会話を行うことで相手への信頼度へも関係してくるでしょう。

## 電話対応のポイント

電話対応は、普段のコミュニケーションと違い、お互いの顔を直接確認することができません。

『相手の表情』を読み取ることや『空気感』を感じること、『反応を確認する』ことが出来ずに『内容を理解してもらえない』や『感情のギャップ』が生まれてしまい、会話が全く違う所へ着地してしまうなどの問題が生じてしまう可能性があります。

**オフィスの第一印象を感動できる応対にするべく、下記のマニュアルに沿って応対を行うようにしていきましょう。**

---

## 満足と感動の違い

| | 定義 | 例 |
| --- | --- | --- |
| **満足** | 完全なこと。十分であること。望みがみちたりて、不平不満がないこと | ラーメン屋で美味しいラーメンが提供される。『出来て当たり前』という評価 |
| **感動** | 物に深く感じて、心を動かすこと | 『ディズニー』や『USJ』のように期待していたサービスよりも遥かに上のサービスを提供される |

### 目指すべきサービス

我々ディーキャリアでは『満足』していただける支援を行うのではなく、 **『感動』して頂ける支援を行う必要があります。**

電話応対の一つでも、相手に感動して頂けるような応対を目指し、ディーキャリアの信頼を上昇させ、ナンバーワンの事業所を達成させましょう。

## 電話応対ルール

### 基本ルール

#### 「もしもし」の使用禁止

『申します』が語源となっており、明治時代の電話が発明された当初に、ちゃんと繋がっているのかの確認のために使用されていました。

**現在では『上から目線に感じてしまう』という観点からマナー違反となっています。**

#### 敬称・敬語の正しい使用

敬称や敬語を正しく使用してください。

#### メモの準備

メモと準備しておいてください。内容は復唱を行います。

#### 3コール以内に受話器を取る

一般的には3コール目が鳴り止む前に受話器を取るケースが多いです。

相手を待たせてしまった場合には **『お待たせいたしました』と枕詞を必ず伝えるようにしましょう。**

#### 静かに切る

受電側であれば先に、かけた側であれば後に電話を切ります。

その際には必ず指で優しく切ってから受話器をおきます。

先に受話器を置いた場合『ガチャン』と音が入ってしまい不快に感じさせてしまいます。

### マナー違反の確認事項

**何度も聞き返す事や伝言内容の失念などは、相手に失礼となります。**

信頼関係を崩す可能性もあるためマナー違反となっております。

不適切な使い方を行ってしまうと印象を悪くしてしまう可能性があるためマナー違反となっております。

## 受電別確認事項一覧

### 関係機関・関係企業からの受電

受電時に以下の項目を確認し、メモに記入してください：

- 電話を受けた日付と時間
- 相手の会社名（部署名）
- 相手の氏名
- 相手の連絡先
- 伝言内容
- 折り返しの連絡が必要な案件か（担当者不在の場合）
- 電話対応者の氏名

### 新規利用者からの受電

受電時に以下の項目を確認し、メモに記入してください：

- 氏名（フルネーム）
- 年齢
- 電話番号（応対可能な時間帯）
- お住まいの地域
- 手帳の有無
- ディーキャリアを知ったきっかけ
- ご不安点や質問事項（伝言）

## 電話応対トークスクリプト

### 関係機関・関係企業からの受電の場合

**電話を受け取った直後：**

```
お電話ありがとうございます。ディーキャリア○○の○○と申します。
```

**要件を確認する際：**

```
お忙しい中お電話いただきまして誠にありがとうございます。
○○の件で○○にお電話とのことでよろしいでしょうか?
```

**担当者に繋ぐ場合：**

```
承知いたしました。
只今○○にお繋ぎいたしますので
しばらくお待ちくださいませ。
```

**担当者が不在の場合：**

```
承知いたしました。
大変恐縮ですが、只今○○が席を
外しております。

○○から直接折り返しさせていただきますの
で、折り返し先のお電話番号を頂戴してもよろし
いでしょうか?
```

**伝言を受け取る場合：**

```
ありがとうございます。

それでは○○から○○様へ折り返しするよう伝言
させていただきます。申し訳ございませんが
しばらくお待ちください。
私○○が責任を持ってお伝えさせていただきます
のでご安心くださいませ。
今後とも引き続きよろしくお願いいたします。

失礼致します。
```

**要件が聞き取れなかった場合：**

```
大変申し訳ございません。
先にご用件をお伺いさせて頂くことは可能でしょ
うか?
```

## よくある質問 Q&A集

### 就労移行とは何ですか?

埼玉県認定の障害福祉サービスの一つで、障害をお持ちの方の就職を支援しております。

### 就労移行で何ができますか?

就労を目指している障害のある方に対して、生活リズムを整えていくこと、就職に関する知識・スキルの提供、就職活動のサポートなどを行っております。

### 対象者は?

就労をご希望されている身体障害・知的障害・精神障害・発達障害・難病のある方で、18歳以上65歳未満の方が対象となっております。

### 手帳は必要ですか?

障害者手帳は必要ございません。医師の診断や住んでいる自治体の判断によっては、利用できる場合もございますので、まずは何でもご相談ください。

### 利用期間などはありますか?

最大2年間の利用が可能です。しかし、通われている方の多くは、半年から1年程度で就労されています。

### 実績など教えてください。

就職率は100%。職場定着率は94%です。就職先としては幅広くございますので、直接担当者からお伝えさせていただきます。

### 利用料金は?

ほとんどのご利用者様が0円でご利用されております。
ご利用を希望されている方の前年度の世帯年収によって、利用料金が異なります。詳しくは担当者からお伝えさせて頂きます。

### 年齢層はどのくらいですか?

有り難いことに幅広い年代の方々に支持されております。
最年少のご利用者様で10代～最高年で60代の方もいらっしゃいます。
現在は若年層のご利用者様が増加しておりますので、比較的他の事業所様よりは低い年齢層となっております。

### 60代でも就職は可能ですか?

はい。全く問題ございません。60代の方でも就職先でお困りになることが無いようサポートさせて頂きますのでご安心ください。

### 一度利用したことがあっても利用できますか?

もちろん可能です。通われていた期間など詳しく教えて頂ければ、残りの期間なども詳しくご説明が可能ですので、担当者に一度ご相談ください。

### 身体障害なのですが利用可能ですか?

はい。もちろん可能です。しかし弊社がバリアフリーではございませんので、自身である程度自走可能であれば問題ございませんがいかがでしょうか?

### 資格は取得できますか?

はい。もちろん可能です。現在資格サポートも実施しておりますので、無料で資格の取得も可能です。ぜひご活用ください。

### 見学や体験は何回可能ですか?

何度でもご活用ください。ご納得頂いた上でお申し込みとなりますので、何度でもご利用いただけます。しかしほとんどの方々は1～2回程度でご決断なさる方が多いですよ。

### 賃金などは発生しますか?

ご利用中は賃金等は発生いたしません。もし金銭面でお悩みの際は、提携している社労士や関係機関と協力して負担が無いようにサポートも可能ですので、まずは担当者へご相談してみてはいかがでしょうか?

### 障害者就労は給与は低いですか?

とんでもございません。ご自身の特性によって変化はありますが、一般企業へご就職される方もいらっしゃいますので、必ずご安心いただける内容ですよ。詳しくは担当者からご説明させて頂きますね。
